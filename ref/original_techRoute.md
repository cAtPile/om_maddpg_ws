# OM-MADDPG 纯 Python 可收敛性验证 — 技术路线

## 0. 核心思路

在完全不依赖 ROS2 / Gazebo / PX4 的前提下，用 **NumPy + PyTorch + Gymnasium** 搭建一个轻量化的 2D 质点运动学仿真环境，复现论文中的 OM-MADDPG 算法并与 MADDPG、DDPG 做对比，**验证三条曲线能否重现论文 Fig 4.7 的趋势**：OM-MADDPG > MADDPG > DDPG。

---

## 阶段一：2D 仿真环境构建（`env/`）

**目标**：实现论文第 4.2 节描述的围捕环境，接口兼容 Gymnasium。

### 1.1 运动学模型

- 质点模型：`v(t+Δt) = v(t) + a(t)·Δt`，`p(t+Δt) = p(t) + v(t)·Δt`
- 加速度为连续动作空间
- Δt = 0.05s（论文 Table 4.5 仿真步长）
- 单回合最大步数 = 100（论文 Table 4.4 maxStep）

### 1.2 任务区域

- 2000m × 2000m 正方形：[-1000, 1000] × [-1000, 1000]
- 所有无人机位置受边界约束，超出边界给予惩罚并反弹

### 1.3 追捕方（3 架同构无人机）

| 参数 | 值 |
|------|-----|
| 数量 | 3 |
| 最大速度 v_max | 100 m/s |
| 最大加速度 a_max | 40 m/s² |
| 通信方式 | 全连通，实时共享位置和速度 |
| 初始位置 | 距离目标约 800~1000m，呈 ~120° 环形分布 |

### 1.4 目标方（1 架无人机）

| 参数 | 值 |
|------|-----|
| 数量 | 1 |
| 最大速度 v_max | 120 m/s |
| 最大加速度 a_max | 50 m/s² |
| 初始位置 | 原点 [0, 0] |
| 初始航向 | 随机 |

### 1.5 障碍物

| 参数 | 值 |
|------|-----|
| 数量 | 3 |
| 形状 | 圆形 |
| 半径范围 | [100, 150] m |
| 静态模式 | 位置随机固定 |
| 动态模式 | 以 30 m/s 匀速直线运动，碰壁反弹并随机调整方向 |

### 1.6 16 通道激光雷达

- 每 22.5° 一条射线，均匀覆盖 360°
- 每条射线返回最近障碍物距离，归一化到 [0, 1]（除以 D_max）
- 用于避障感知

### 1.7 三种目标逃逸策略

1. **随机逃逸（Random）**：每步随机选择方向和速度大小
2. **APF 规则逃逸（Rule-based）**：追捕者→斥力，区域边缘外侧→引力，合力决定运动方向
3. **智能逃逸（DDPG）**：预训练 DDPG 策略网络，具备避障和逃脱能力

### 1.8 围捕成功判定（阿波罗尼奥斯圆）

- 每架追捕者与目标之间计算阿波罗尼奥斯圆（圆心 O_i，半径 r_i）
- 判定条件：相邻圆两两相交 + 目标被包围圈封闭 + 所有追捕者距目标距离 < d_capture（300m）
- 初期可用简化判定（距离 + 角度分布），后期替换为完整几何判定

### 1.9 奖励函数（五部分）

| 奖励项 | 符号 | 含义 |
|--------|------|------|
| 目标靠近奖励 | R_near | 鼓励以较大速度沿最优方向逼近目标 |
| 多阶段协作奖励 | R_stage | 追踪/包围/围捕三阶段自适应，含编队保持和包围收缩 |
| 任务完成奖励 | R_finish | 满足阿波罗尼奥斯圆条件时触发终局奖励 |
| 安全奖励 | R_safe | 基于 16 维 LiDAR 读数，惩罚接近障碍物 |
| 时间惩罚 | R_time | 每步固定负奖励，鼓励快速完成 |

## 阶段二：LSTM-PINN 对手建模模块（`models/`）

**目标**：实现论文第 4.3 节的对手轨迹预测网络。

### 2.1 网络结构

```
输入: 10步历史 [x, y, vx, vy] → shape (batch, 10, 4)
  ↓
LSTM Layer 1 (hidden=128) + ReLU + Dropout(0.2)
  ↓
LSTM Layer 2 (hidden=64) + ReLU + Dropout(0.2)
  ↓
FC (32) + ReLU
  ↓
输出: 预测下一时刻位置 [x̂, ŷ] → shape (batch, 2)
```

### 2.2 PINN 损失函数

| 损失项 | 公式 | 权重 |
|--------|------|------|
| L_data | MSE(预测位置, 真实位置) | λ_data = 0.7 |
| L_phy | MSE(p_phy, 预测位置)，其中 p_phy = p_t + v_pred·Δt | λ_phy = 0.25 |
| L_smooth | ||a_{t+1} - a_t||²（加速度平滑约束） | λ_smooth = 0.05 |

总损失：`L_total = 0.7*L_data + 0.25*L_phy + 0.05*L_smooth`

### 2.3 预训练数据

- 运行三种逃逸策略各若干回合，采集 (历史10步, 下一步位置) 配对
- 数据集划分：训练:验证:测试 = 70:15:15
- 目标：验证集 MAE 达到 ~0.035（与论文一致）

### 2.4 消融实验

- 纯 LSTM（无 PINN 约束）vs LSTM-PINN
- 期望：PINN 版本 MAE 降低约 50%，收敛更快

## 阶段三：算法实现（`algorithms/`）

**目标**：实现论文第 4.4 节的 DDPG、MADDPG、OM-MADDPG 三种算法。

### 3.1 DDPG（基准 1）

- 每个追捕者独立训练，无法获取队友信息
- 单智能体 Actor-Critic 架构
- 状态空间：自身状态 + LiDAR + 目标相对位置
- 无对手建模

### 3.2 MADDPG（基准 2）

- CTDE 框架
- Critic 获取全局状态和联合动作
- Actor 仅使用局部观测
- 经验回放池 + 软更新
- 无对手建模

### 3.3 OM-MADDPG（目标算法）

- 在 MADDPG 基础上增加 LSTM-PINN 对手建模模块
- 每个追捕者的状态空间额外包含：LSTM-PINN 预测的目标未来位置
- 其他结构与 MADDPG 一致

### 3.4 网络细节

**Actor 网络**：
- 输入：局部观测（自身状态 + 队友位置 + 16维LiDAR + 目标相对位置 + 预测目标位置）
- 隐藏层：256 → 128
- 激活：ReLU
- 输出：2维加速度 [ax, ay]（tanh 激活，缩放到 [-a_max, a_max]）

**Critic 网络**：
- 输入：所有追捕者的联合观测 + 联合动作
- 隐藏层：256 → 128
- 激活：ReLU
- 输出：Q 值标量

### 3.5 训练超参数（对齐论文 Table 4.4）

| 参数 | 值 |
|------|-----|
| 折扣因子 γ | 0.9 |
| 软更新 τ | 0.01 |
| 经验池大小 | 10000 |
| 批次大小 | 128 |
| Actor 学习率 | 0.001 |
| Critic 学习率 | 0.002 |
| 最大训练回合 | 5000 |
| 单回合最大步数 | 100 |
| 探索噪声 | OU 噪声，随训练衰减 |
| 优化器 | Adam |

## 阶段四：对比实验与收敛性评估（`train/` + `eval/`）

### 4.1 训练任务

在「3 追捕 vs 1 智能逃逸目标 + 3 动态障碍物」场景下，分别训练 DDPG、MADDPG、OM-MADDPG

### 4.2 需要产出的收敛性曲线

1. **Episode Reward 曲线**（对标论文 Fig 4.7a）
   - 期望：OM-MADDPG 最早收敛（~2500 回合），收敛值最高
   - MADDPG 渐进式提升，次之
   - DDPG 震荡剧烈，收敛值最低

2. **Episode 完成步数曲线**（对标论文 Fig 4.7b）
   - 期望：OM-MADDPG ~72 步，MADDPG ~90 步，DDPG ~95 步

3. **围捕成功率柱状图**（对标论文 Fig 4.8）
   - 6 种场景：静态/动态障碍物 × 随机/规则/智能逃逸
   - 期望：OM-MADDPG 各场景均最高，智能逃逸+动态障碍物场景 > 70%

### 4.3 收敛判定标准

| 指标 | 阈值 |
|------|------|
| OM-MADDPG 奖励收敛 | 2500~3000 回合内趋于平稳 |
| 奖励排序 | OM-MADDPG > MADDPG > DDPG |
| 步数排序 | OM-MADDPG < MADDPG < DDPG |
| 静态场景成功率 | > 80% |
| 动态场景成功率 | > 60% |

## 风险点与注意事项

1. **训练时间**：5000 回合在 CPU 上单次实验可能需要数小时。建议先用 2000 回合验证趋势，确认代码正确后再跑完整 5000 回合。
2. **LSTM-PINN 预训练**：初期用随机 + APF 策略生成 500~1000 条轨迹即可，不必达到论文的 1600 条。
3. **智能逃逸目标**：需预训练 DDPG 逃逸策略，建议最后实现。前期先用随机 + APF 验证主算法。
4. **阿波罗尼奥斯圆判定**：初期可简化为「所有追捕者距目标 < d_capture + 角度分布均匀」判定，后期替换为完整几何计算。
5. **随机种子**：固定 numpy/torch/random 种子，确保实验可复现。
6. **TensorBoard**：建议集成 TensorBoard 或 WandB 记录训练曲线，便于实时监控。
